# RECALL

Estudo gamificado em HTML, CSS e JavaScript, pensado para GitHub Pages.

## Recursos da primeira versão
- Dashboard com XP, streak, quantidade de cards e precisão
- Decks salvos em localStorage
- Criador/importador por linhas no formato `Pergunta | Resposta`
- Separador configurável
- Flashcards com animação de virar
- Quiz solo com alternativas, pontuação e feedback
- Partículas e microanimações
- Sons gerados pelo Web Audio API, sem depender de arquivos binários
- Bootstrap + Bootstrap Icons + Google Fonts

## Estrutura
`index.html` é o hub. As páginas ficam em `pages/`, estilos em `css/` e lógica em `js/`.

## GitHub Pages
Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`. O site é totalmente client-side e não precisa de servidor.
